# 模块 01：原型机制与表现优化

状态：O-001～O-002 实现与本地验证已完成，等待用户验收
对应批次：D2

## 模块目标

对已验证的原型循环做有边界的优化，提高操作、判定和反馈质量，同时保持核心玩法结论不被未经验证的新系统替换。

## 固定边界

- 只处理用户明确列出的优化条目。
- 每项优化注明属于机制、数值、反馈、界面或表现。
- 涉及 Boss 阶段内容时转入模块 02；涉及转场、背景或骨架资源时转入对应模块。
- 碰撞与表现修改必须分别说明，避免美术变化暗改判定。
- 每项优化保留修改前基线、目标效果和可回归的验收方法。

## 已确认优化条目

### O-001：Boss 拆分为头部与手握武器

类型：机制判定、角色结构与开火表现。

- Boss 的可见角色拆分为“头部”和“手握武器”两个部分；常规战斗中的手握武器贴图为已经包含武器与握持它的手的完整独立资源。
- Boss 使用不可见的根锚点承载阶段移动；头部与武器分别在根锚点附近独立游离，因此共享整体位移，但保留有限的相对位置变化。
- 两个局部游离都必须连续、平滑且范围受限，不使用逐帧随机跳动；具体幅度和速度作为集中参数在实装时调试。
- 现有 Boss 只保留头部与手握武器两个可见部位。所有阶段均只有头部可以受伤，不再设置其他 Boss 受击部位。
- 头部视觉体积较大，逻辑受击区使用跟随头部的圆形碰撞体；碰撞半径约为可见头部半径的 75%～80%，避免视觉边缘命中产生苛刻感。
- 手握武器是纯表演部位，不参与受击、阻挡或其他碰撞判定。
- 敌方子弹从武器的枪口／发射点生成，发射点随武器当前姿态和相对游移同步更新。
- 一般情况下武器保持固定朝向，不持续追踪玩家；实际子弹在生成瞬间独立瞄准玩家屁股。阶段机制如需例外，必须在对应阶段文档中明确声明。
- 转阶段会更换武器外形，但头部、武器和根锚点的基本相对位置关系保持不变。
- 每次开火向武器追加一次有上限的后坐冲量，再通过弹簧缓动回到局部游离位置；连续开火允许累积到上限，但不得无限后漂。后坐力属于显示动画，不直接改变弹道、射速或 Boss 主运动。

初步验收关注：头部命中是否清楚、穿过武器是否不会产生错误判定、枪口是否与子弹生成位置一致、连续开火时后坐力是否稳定，以及两部分的相对游离是否生动但不干扰弹幕判读。

#### O-001 实现基线（2026-09-28）

- 使用不可见根锚点保留原型 Boss 在屏幕右侧的整体移动；头部和武器分别通过不同频率、不同初相的正弦分量游离，保证连续、有界且可由固定种子复现。
- 头部可见半径暂定 58 px，唯一逻辑受击圆半径暂定 46 px，比例为 79.3%；武器和手部不暴露任何碰撞体。
- 头部基准偏移为 `(8, -34)`，游离半径为 `(12, 9)` px；武器基准偏移由 `(-8, 43)` 下移为 `(-8, 68)`，游离半径保持 `(9, 7)` px。模型额外强制头部与武器中心的最小垂直间距为 88 px，两者在独立游离的极值姿态下也不会重合。
- 枪口是武器局部坐标的派生点，子弹生成、显示和碰撞模型共用同一帧位姿；武器视觉始终朝左，原型现有的子弹独立瞄准保持不变。
- 后坐沿水平反方向显示；根据首轮验收反馈，将每发速度冲量由 78 提高到 156 px/s、速度上限由 185 提高到 370 px/s、偏移上限由 18 提高到 36 px，后坐强度为原来的 2 倍。弹簧强度 78 与阻尼 13 保持不变，因此回位节奏不变；物理积分内部子步长不超过 1/120 秒。
- 本批仅替换 Boss 结构、受击区和开火显示；玩家、弹种、能量、强化、大招、原型三阶段压力参数都保持不变。

#### O-001 回归结果

- Boss 专项自动测试覆盖：唯一头部碰撞体及 75%～80% 比例、头部／武器独立有界游离、2000 帧最小间距约束、枪口出弹坐标、连续开火后坐速度封顶和弹簧回位。
- `npm run test:combat` 49/49、`npm run test:demo` 9/9、`npm run typecheck` 和 `npm run build` 全部通过；构建仅有 Phaser 主包体积的非阻断警告。
- 默认本地网址 `/` 已实机画面检查，Boss 仅显示大头和手握武器，不显示根锚点或旧躯干；游戏能从初始生命正常进入战斗和失败状态。

### O-002：大招弹丸一换一与独立伤害

类型：技能机制与伤害结算。

- 大招吸收阶段记录实际纳入的弹丸总数 `N`；进入连射时严格生成 `N` 颗我方弹丸，不再追加基础弹数，也不再对弹数使用 18 颗封顶。
- 若未吸收任何弹丸，则不生成大招弹，也不造成伤害。发射间隔、移动速度、局部高度偏移和轻微散射保持原型已验收参数。
- 每颗大招弹分别使用扫掠圆判定 Boss 头部；每颗实际命中的弹丸立即单独造成 1 点伤害、生成命中动效并消失。飞出场景或未命中的弹丸不产生伤害。
- 删除原型的“按吸收数计算聚合伤害，连射结束后统一扣血”路径；大招状态机的收尾事件不再承担 Boss 伤害结算。

O-002 自动测试覆盖 57 颗吸收对应 57 颗发射、零吸收时零输出、多颗弹丸在同一逻辑帧命中时分别生成独立的 1 点伤害事件，以及原有的延迟连射、命中消失和固定种子复现。
