# Prototype assets

This directory is reserved for browser-served game assets.

- `character/`: player rig and character artwork
- `player-a/`: D6 first-pass 11-part realistic player artwork
- `boss/`: test boss artwork
- `bullets/`: projectile artwork
- `backgrounds/`: Demo single-layer scrolling background
- `combat/`: D7 bullets, rockets, laser, ammo barrel, summoned guns and creepers
- `audio/`: sound effects and music
